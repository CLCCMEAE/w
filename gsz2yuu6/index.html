Mode d'import
Cochez ci-dessous ce qui identifie une ligne, pour que les lignes déjà présentes soient reconnues.
Le widget compare chaque ligne du fichier à celles de la table sur les colonnes que vous cochez : une adresse électronique, un numéro de dossier, un code. Si aucune colonne ne suffit à elle seule, cochez-en plusieurs, c'est alors leur combinaison qui identifie la ligne, par exemple un pays et un nom de poste. Sans cette indication, l'import ne peut pas être lancé dans ce mode.
