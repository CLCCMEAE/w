Paramétrage

  1. Les nouvelles personnes arrivent en « Demande à étudier », inactives.

  2. Ce registre seul ne donne aucun accès au document. La fenêtre Inviter des personnes du document est la seule porte d'entrée : une personne qui n'y figure pas ne pourra jamais ouvrir le document, même si elle est dans ce registre.
    1. Copiez les adresses des personnes actives avec le bouton ci-dessous (une adresse par ligne).
    2. En haut à droite du document, cliquez sur l'icône de partage, à côté de la loupe.
    3. Dans le menu qui s'ouvre, choisissez Gérer les utilisateurs : la fenêtre Inviter des personnes apparaît.
    4. Cliquez sur Invitation multiple, collez les adresses, choisissez l'accès sous la zone de saisie (Propriétaire, Éditeur ou Lecture seule), puis validez.
    5. De retour dans Inviter des personnes, vérifiez le rôle de chaque personne, puis cliquez sur Confirmer.
    À coller dans « Invitation multiple »

  3. Le registre. Il affine les droits de base (Propriétaire, Éditeur, Lecture seule) donnés dans « Gérer les utilisateurs ». Avec des champs personnalisés (zone géographique, domaine…), des règles peuvent limiter chaque utilisateur à son périmètre : voir l'onglet Les droits.

    Retirer un accès en urgence. Décocher Actif bloque aussitôt l'accès de la personne, si la règle d'or est en place (onglet Les droits). Pour un retrait définitif, retirez aussi l'invitation dans Gérer les utilisateurs (icône de partage en haut à droite).

    Mode structure. Verrou contre les modifications de structure accidentelles par un propriétaire. Il n'agit que si les deux règles de structure sont posées dans les permissions avancées.

    Prérequis : l'attribut utilisateur Utilisateur (propriété user.Email, table BIBLIOTHEQUE_CENTRALE, colonne EMAIL), décrit dans l'onglet Les droits.

    1. Dans le panneau de gauche du document, rubrique Outils, ouvrez Permissions avancées, puis, dans le bloc des Règles spéciales, droits de modification de la structure, ajouter la règle user.Access == OWNER and user.Utilisateur.MODE_ADMIN_VALIDE == True : autoriser.

    2. Juste en dessous, pour tous les autres : refuser, avec le message « Seuls les propriétaires ayant activé leur mode structure peuvent modifier la structure du document ».

    3. Vérifier que seuls les propriétaires peuvent modifier les lignes de la gestion des utilisateurs : règle sur BIBLIOTHEQUE_CENTRALE, condition user.Access != OWNER and rec.WIDGET in ("Gestion des utilisateurs", "utilisateurs"), refuser Modification, Création et Suppression.

    À savoir : mode structure désactivé, les actions qui modifient la structure échouent aussi dans les widgets : création de table ou de colonne à l'import, descriptions de la Documentation, champs personnalisés de ce widget. Activer son mode structure le temps de l'opération, puis le désactiver : sans cela, il se referme seul après 2 heures (au plus tard au recalcul suivant du document). Ce verrou protège des erreurs, pas de la malveillance : un propriétaire peut toujours activer son propre mode structure.
